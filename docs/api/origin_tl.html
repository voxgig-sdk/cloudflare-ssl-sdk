Request body

application/json

Property Type Required Description
value array of string Yes List of TLS compliance modes that constrain the key-exchange algorithms Cloudflare may use when establishing the TLS connection to the zone's origin. Currently supported values are fips (FIPS-approved curves) and pqh (post-quantum hybrid). Future modes (for example cnsa2) may be added; clients should treat unknown values as opaque strings. Multiple modes are combined as the intersection of their permitted algorithm lists; selections whose intersection is empty are rejected. An empty list clears the constraint.
