Request body

application/json

Property Type Required Description
csr string Yes The Certificate Signing Request (CSR). Must be newline-encoded.
hostnames array of string Yes Array of hostnames or wildcard names bound to the certificate. Hostnames must be fully qualified domain names (FQDNs) belonging to zones on your account (for example, example.com or sub.example.com). Wildcards are supported only as a *. prefix for a single level (for example, *.example.com). Double wildcards (*.*.example.com) and interior wildcards (foo.*.example.com) are not allowed. The wildcard suffix must be a multi-label domain (*.example.com is valid, but *.com is not). Unicode/IDN hostnames are accepted and automatically converted to punycode.
request_type enum: origin-rsa, origin-ecc, keyless-certificate Yes Signature type desired on certificate ("origin-rsa" (rsa), "origin-ecc" (ecdsa), or "keyless-certificate" (for Keyless SSL servers).
requested_validity enum: 7, 30, 90, 365, 730, 1095, ... No The number of days for which the certificate should be valid.
